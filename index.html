Cómo publicar en GitHub Pages (Gratis)

Pasos para publicar la web de la Cafetería Colegial CCB en GitHub Pages:

  1. Guardar este archivo: Guarda este código con el nombre index.html en tu computadora.
  2. Crear Repositorio en GitHub: Entra a GitHub.com, crea un repositorio con el nombre cafeteria-colegial-ccb y marca la opción "Public".
  3. Subir el archivo: Haz clic en "uploading an existing file", arrastra index.html y presiona "Commit changes".
  4. Activar GitHub Pages: Ve a Settings → Pages → Selecciona la rama main o master y guarda.
  5. ¡Sitio web publicado! Tu página estará activa en: https://tu-usuario.github.io/cafeteria-colegial-ccb
